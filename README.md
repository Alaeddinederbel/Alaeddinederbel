## ⚡ About Me

I build systems where **hardware meets software in real time**. My work lives close to the metal **STM32, ESP32, embedded Linux** and I care about firmware correctness, deterministic timing, and systems that hold up outside the lab.

Most recently, I designed the navigation software for an autonomous robot at LATIS Laboratory, optimizing a ROS2 pipeline down to sub-100ms latency at 30 FPS the kind of real-time constraint that shapes how I approach every embedded problem.
